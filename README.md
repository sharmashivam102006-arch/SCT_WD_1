# SCT_WD_1 - Responsive Landing Page

## 📌 Overview

This project was developed as part of the SkillsCraft Technology Web Development Internship.

The objective of this task was to create an interactive and responsive landing page featuring a fixed navigation menu that changes appearance when scrolling and highlights menu items on hover.

## 🚀 Features

- Fixed Navigation Bar
- Scroll-based Navbar Styling
- Interactive Hover Effects
- Smooth Scrolling Navigation
- Responsive Design
- Hero Section with CTA Buttons
- About Section
- Services Section
- Portfolio Showcase
- Testimonials Section
- Contact Form
- Modern Dark UI Design
- Mobile Friendly Layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
